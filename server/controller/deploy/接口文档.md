# Deploy API文档

## 1. 部署服务

- **URL**: `/api/deploy/service` (Assuming the router is configured this way)
- **Method**: `POST`
- **Description**: 部署服务到目标机器 (Deploy a service to target machines).
- **Request Body**:

```json
{
  "serviceId": 1,
  "targetIds": [1, 2],
  "comment": "This is a deployment comment",
  "useFastMode": false
}
```

**Request Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `serviceId` | `integer` | 服务ID (Service ID) |
| `targetIds` | `array[integer]` | 目标机器ID列表 (List of target machine IDs) |
| `comment` | `string` | 部署备注 (Deployment comment) |
| `useFastMode` | `boolean` | 是否使用快速模式 (Whether to use fast mode) |

- **Response**: `200 OK`

```json
{
  "message": "部署成功"
}
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `message` | `string` | 操作结果信息 (Operation result message) |
