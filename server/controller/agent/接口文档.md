# Agent API文档

## 1. 获取所有Agent

- **URL**: `/api/agent/all` (Assuming the router is configured this way)
- **Method**: `GET`
- **Description**: 获取所有目标机器信息，按host去重 (Get all target machine information, deduplicated by host).
- **Request Parameters**: None
- **Response**: `200 OK`

```json
[
  {
    "id": 1,
    "serviceId": 1,
    "host": "192.168.1.1",
    "port": 8080,
    "secretKey": "some-secret-key",
    "servicePath": "/path/to/service",
    "comment": "This is a comment",
    "exePath": "/path/to/service/executable",
    "exeParams": "--param1 value1"
  }
]
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `integer` | 唯一标识 (Unique identifier) |
| `serviceId` | `integer` | 服务id (Service ID) |
| `host` | `string` | 目标主机 (Target host) |
| `port` | `integer` | 目标端口 (Target port) |
| `secretKey` | `string` | 密钥 (Secret key) |
| `servicePath` | `string` | 服务路径 (Service path) |
| `comment` | `string` | 备注 (Comment) |
| `exePath` | `string` | 程序执行完整路径 (Full path to the executable) |
| `exeParams` | `string` | 程序执行参数 (Execution parameters) |

## 2. 获取Agent版本

- **URL**: `/api/agent/version` (Assuming the router is configured this way)
- **Method**: `GET`
- **Description**: 获取目标机器上Agent的版本 (Get the version of the agent on the target machine).
- **Request Parameters**:

| Parameter | Type | Location | Description |
| :--- | :--- | :--- | :--- |
| `targetId` | `string` | Query | 目标机器ID (Target machine ID) |

- **Response**: `200 OK`

```json
{
  "version": "1.0.0"
}
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `version` | `string` | Agent版本号 (Agent version number) |

## 3. 更新Agent

- **URL**: `/api/agent/update` (Assuming the router is configured this way)
- **Method**: `POST`
- **Content-Type**: `multipart/form-data`
- **Description**: 更新目标机器上的Agent (Update the agent on the target machine).
- **Request Parameters**:

| Parameter | Type | Location | Description |
| :--- | :--- | :--- | :--- |
| `file` | `file` | Form Data | Agent更新文件 (Agent update file) |
| `agentServiceName` | `string` | Form Data | Agent服务名称 (Agent service name) |
| `targetId` | `integer` | Form Data | 目标机器ID (Target machine ID) |

- **Response**: `200 OK`

```json
{
  "message": "更新指令已发送"
}
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `message` | `string` | 操作结果信息 (Operation result message) |
