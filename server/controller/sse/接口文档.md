# 接口文档

## SSE

### 1. SSE 连接

- **URL**: `/api/sse/connect`
- **Method**: `GET`
- **Description**: 建立一个 Server-Sent Events (SSE) 连接，用于接收服务器推送的消息。
- **广播方式**: 每个在线连接按顺序接收完整日志，连接断开只清理自身订阅，不影响其他页面。每 15 秒发送一次 SSE 注释心跳；新连接不回放历史日志。
- **Response**:
    - `Content-Type`: `text/event-stream`
    - A stream of events. Each event has the following format:
      ```
      event: message
      data: <message content>
      ```

### 2. 发送消息

- **URL**: `/api/sse/send`
- **Method**: `GET`
- **Description**: 发送一条消息给所有连接的 SSE 客户端。
- **Query Params**:
    - `message` (required, string): 要发送的消息内容。
- **Response**:
    - `200 OK`
    - JSON:
      ```json
      {
        "message": "message sent"
      }
      ```
