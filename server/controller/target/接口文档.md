# 接口文档

## Target

### 1. 获取部署目标列表

- **URL**: `/api/target/list`
- **Method**: `GET`
- **Query Params**:
    - `serviceId` (optional, string): 服务ID
- **Response**: `[]model.DeployTarget`
    - `id`: int
    - `serviceId`: int
    - `host`: string
    - `port`: int
    - `secretKey`: string
    - `servicePath`: string
    - `comment`: string
    - `exePath`: string
    - `exeParams`: string

### 2. 获取单个部署目标

- **URL**: `/api/target/:id`
- **Method**: `GET`
- **URL Params**:
    - `id` (required, string): 部署目标ID
- **Response**: `model.DeployTarget`
    - `id`: int
    - `serviceId`: int
    - `host`: string
    - `port`: int
    - `secretKey`: string
    - `servicePath`: string
    - `comment`: string
    - `exePath`: string
    - `exeParams`: string

### 3. 获取所有服务

- **URL**: `/api/target/service`
- **Method**: `GET`
- **Query Params**:
    - `host` (optional, string): 主机地址
- **Response**: `[]GetAllServiceResponse`
    - `host`: string
    - `serviceName`: string
    - `environment`: string
    - `groupName`: string
    - `port`: int

### 4. 获取所有主机

- **URL**: `/api/target/hosts`
- **Method**: `GET`
- **Response**: `[]GetAllHostsResponse`
    - `host`: string

### 5. 创建部署目标

- **URL**: `/api/target/create`
- **Method**: `POST`
- **Request Body**: `CreateTargetRequest`
    - `serviceId`: int (required)
    - `host`: string (required)
    - `port`: int (required)
    - `secretKey`: string
    - `servicePath`: string
    - `comment`: string
    - `exePath`: string
    - `exeParams`: string
- **Response**: `model.DeployTarget`

### 6. 更新部署目标

- **URL**: `/api/target/update`
- **Method**: `POST`
- **Request Body**: `UpdateTargetRequest`
    - `id`: int (required)
    - `serviceId`: int
    - `host`: string
    - `port`: int
    - `secretKey`: string
    - `servicePath`: string
    - `comment`: string
    - `exePath`: string
    - `exeParams`: string
- **Response**: `SuccessResponse`
    - `message`: string

### 7. 删除部署目标

- **URL**: `/api/target/delete/:id`
- **Method**: `POST`
- **URL Params**:
    - `id` (required, string): 部署目标ID
- **Response**: `SuccessResponse`
    - `message`: string
