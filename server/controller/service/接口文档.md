# 接口文档

## Service

### 1. 获取服务状态

- **URL**: `/api/service/status/:serviceId`
- **Method**: `GET`
- **URL Params**:
    - `serviceId` (required, string): 服务ID
- **Response**: `[]target.ServiceStatusInfo`
    - `Host`: string
    - `Port`: int
    - `ServiceName`: string
    - `Status`: string
    - `Err`: string

### 2. 获取所有部署服务

- **URL**: `/api/service/list`
- **Method**: `GET`
- **Response**: `[]model.DeployService`
    - `id`: int
    - `serviceName`: string
    - `environment`: string
    - `groupName`: string
    - `port`: int
    - `packagePath`: string
    - `excludeFiles`: string
    - `healthCheckUrl`: string
    - `deployHook`: string
    - `comment`: string

### 3. 创建部署服务

- **URL**: `/api/service/create`
- **Method**: `POST`
- **Request Body**: `model.DeployService`
    - `serviceName`: string
    - `environment`: string
    - `groupName`: string
    - `port`: int
    - `packagePath`: string
    - `excludeFiles`: string
    - `healthCheckUrl`: string
    - `deployHook`: string
    - `comment`: string
- **Response**:
    - `affected`: 1
    - `data`: `model.DeployService`

### 4. 更新部署服务

- **URL**: `/api/service/update`
- **Method**: `POST`
- **Request Body**: `model.DeployService`
    - `id`: int (required)
    - `serviceName`: string
    - `environment`: string
    - `groupName`: string
    - `port`: int
    - `packagePath`: string
    - `excludeFiles`: string
    - `healthCheckUrl`: string
    - `deployHook`: string
    - `comment`: string
- **Response**:
    - `affected`: 1

### 5. 删除部署服务

- **URL**: `/api/service/delete/:id`
- **Method**: `POST`
- **URL Params**:
    - `id` (required, string): 服务ID
- **Response**:
    - `affected`: 1

### 6. 安装服务

- **URL**: `/api/service/install-service`
- **Method**: `POST`
- **Request Body**: `InstallServiceRequest`
    - `serviceId`: int (required)
    - `targetIds`: []int (required)
- **Response**:
    - `message`: "服务安装成功"

### 7. 删除服务

- **URL**: `/api/service/delete-service`
- **Method**: `POST`
- **Request Body**: `DeleteServiceRequest`
    - `serviceName`: string (required)
    - `targetIds`: []int (required)
- **Response**:
    - `message`: "服务删除成功"
