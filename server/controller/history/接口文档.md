# History API文档

## 1. 获取部署历史

- **URL**: `/api/history/:serviceId` (Assuming the router is configured this way)
- **Method**: `GET`
- **Description**: 获取指定服务的部署历史 (Get the deployment history of a specified service).
- **Request Parameters**:

| Parameter | Type | Location | Description |
| :--- | :--- | :--- | :--- |
| `serviceId` | `integer` | URL Path | 服务ID (Service ID) |

- **Response**: `200 OK`

```json
[
  {
    "id": 1,
    "serviceId": 1,
    "deployTime": "2025-08-15T10:00:00Z",
    "comment": "This is a deployment comment"
  }
]
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `integer` | 唯一标识 (Unique identifier) |
| `serviceId` | `integer` | 服务ID (Service ID) |
| `deployTime` | `datetime` | 部署时间 (Deployment time) |
| `comment` | `string` | 备注 (Comment) |

## 2. 获取部署历史分页列表

- **URL**: `/api/history` (Assuming the router is configured this way)
- **Method**: `GET`
- **Description**: 获取部署历史的分页列表 (Get a paginated list of deployment history).
- **Request Parameters**:

| Parameter | Type | Location | Description |
| :--- | :--- | :--- | :--- |
| `page` | `integer` | Query | 页码 (Page number) |
| `pageSize` | `integer` | Query | 每页数量 (Number of items per page) |
| `serviceId` | `integer` | Query | (Optional) 服务ID (Service ID) |

- **Response**: `200 OK`

```json
{
  "data": [
    {
      "id": 1,
      "serviceId": 1,
      "serviceName": "MyService",
      "deployTime": "2025-08-15T10:00:00Z",
      "comment": "This is a deployment comment",
      "environment": "Production"
    }
  ],
  "total": 100
}
```

**Response Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `data` | `array` | 部署历史列表 (List of deployment history) |
| `total` | `integer` | 总数 (Total number of items) |

**`data` object Fields**:

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | `integer` | 唯一标识 (Unique identifier) |
| `serviceId` | `integer` | 服务ID (Service ID) |
| `serviceName` | `string` | 服务名称 (Service name) |
| `deployTime` | `datetime` | 部署时间 (Deployment time) |
| `comment` | `string` | 备注 (Comment) |
| `environment` | `string` | 环境 (Environment) |
