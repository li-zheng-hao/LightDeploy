# Agent SSE 接口文档

## 接口概览

本文档描述了Agent的Server-Sent Events (SSE)接口，用于实时推送消息到客户端。

## 1. SSE连接

### 接口信息
- **URL**: `GET /api/sse/sse`
- **功能**: 建立SSE连接，接收实时消息推送
- **Content-Type**: `text/event-stream`

### 请求参数
无

### 响应格式
SSE响应采用标准的事件流格式：

```
event: message
data: SSE连接已建立

event: message
data: 实际消息内容
```

### 响应字段说明

| 字段 | 说明 |
|------|------|
| event | 事件类型，固定为 "message" |
| data | 消息内容，可以是任意字符串 |

### 连接建立流程

1. 客户端发起GET请求到 `/api/sse/sse`
2. 服务器设置必要的SSE headers
3. 发送初始化消息："SSE连接已建立"
4. 建立长连接，等待消息推送

### 消息推送机制

- 服务器通过 `sse.MessageChan` 接收消息
- 消息会实时推送给所有已连接的客户端
- 支持多客户端同时连接

### 连接管理

#### 连接标识
- 每个连接都有唯一的标识符（基于内存地址）
- 连接建立和关闭都会记录日志

#### 连接关闭
连接会在以下情况下自动关闭：
1. 客户端主动断开连接
2. 服务器关闭（调用 `ShutdownSSE()` 函数）
3. 网络异常

#### 清理机制
- 连接关闭时会调用 `sse.ClearAllMessage()` 清理消息
- 支持优雅关闭所有SSE连接

### 使用示例

#### JavaScript客户端示例
```javascript
const eventSource = new EventSource('/api/sse/sse');

eventSource.onmessage = function(event) {
    console.log('收到消息:', event.data);
};

eventSource.onerror = function(event) {
    console.error('SSE连接错误:', event);
    eventSource.close();
};
```

#### 关闭连接
```javascript
eventSource.close();
```

### 注意事项

1. **长连接**: SSE连接会保持打开状态，直到客户端或服务器主动关闭
2. **自动重连**: 客户端断开后，EventSource会自动尝试重连
3. **消息格式**: 所有消息都通过 `event: message` 和 `data:` 字段传输
4. **并发支持**: 支持多个客户端同时连接，每个连接独立管理
5. **内存管理**: 连接关闭时会自动清理相关资源
6. **日志记录**: 所有连接建立、消息发送、连接关闭都会记录详细日志

### 错误处理

- 网络异常时连接会自动关闭
- 服务器关闭时会优雅地关闭所有SSE连接
- 客户端可以通过 `onerror` 事件处理连接错误

### 性能考虑

- 使用Gin框架的 `CloseNotify()` 机制检测客户端断开
- 消息通过channel异步处理，避免阻塞
- 支持大量并发连接
